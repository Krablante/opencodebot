# Язык интерфейса

[English](../en/interface-language.md) · [Русский](interface-language.md) · [Все языки](../README.md)

У бота один общий язык для всех тем, получателей, меню, кнопок и асинхронных уведомлений. Переключи его в **General → Настройки → Язык и дополнительные настройки** либо командой:

```text
/lang
/lang eng
/lang ru
```

`/lang en` — сокращение `eng`. Выбор хранится как `ui.language` в `state.json`, переживает рестарт и сразу применяется ко всем темам. Команды остаются английскими. Панель и ответ переключаются немедленно; описания slash-меню обновляются через Telegram. При временном отказе синхронизации текст уже использует новый язык, а старт повторяет меню.

## Область действия

Переводятся собственные тексты бота: справка, описания команд, кнопки, статусы/ошибки, очередь/reset/компакция/контекст, служебные темы, вопросы, обновления, голосовое управление, финальные и аварийные уведомления, статические подписи инструментов.

Текст пользователя/модели, расшифровки, варианты вопросов, пути/имена файлов, ID серверов/моделей и рабочие журналы не переводятся. Динамическая диагностика backend может оставаться на языке источника внутри локализованного сообщения. Язык озвучки задают отдельные prompt/TTS-настройки. Старая история и названия тем не меняются от переключения языка.

## Конфигурация

```json
{ "ui": { "defaultLanguage": "en" } }
```

`en` и `ru` задают язык нового состояния без выбора. `eng`, `rus` и соответствующие английские названия нормализуются. Сохранённый `/lang` важнее этого начального значения.

## Каталоги исходников

Переводы находятся в `src/i18n/index.mjs`, `en.mjs` и `ru.mjs`. Ключи и типы значений должны совпадать: проверка при загрузке модуля останавливает неполный перевод вместо смешанного интерфейса. Часть персональных меню использует парные строки через `localText`; новый язык интерфейса требует расширить и каталог, и такие места.

Языки документации независимы от языка приложения. Для нового руководства достаточно `docs/<код-языка>/` и навигации [индекса](../README.md); исходники бота менять не нужно.

## Проверка

Выбери русский и проверь General, slash-меню, `/help`, `/session`, `/tts` и безвредный статус/ошибку. Проверь асинхронный вопрос или уведомление. Повтори по-английски и верни привычный язык. Переключение не требует рестарта или развёртывания.
