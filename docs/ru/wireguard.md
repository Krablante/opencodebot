# Необязательный доступ WireGuard

[English](../en/wireguard.md) · [Русский](wireguard.md) · [Все языки](../README.md)

WireGuard даёт удалённому телефону/ноутбуку приватный маршрут к веб-интерфейсу OpenCodez. Опрос Telegram, сессии, файлы и LAN независимы от него. Если уже есть доверенный VPN, используй его; не открывай порт OpenCodez прямо в интернет.

## Требования

Встроенный помощник работает на Linux с `wg`, `wg-quick`, systemd, iptables и sudo. Необязательный `qrencode` создаёт QR телефона. Пробрось один UDP-порт роутера на этот хост, выбери публичный endpoint и узнай реальные LAN subnet/DNS/интерфейс. Клиенты используют официальное приложение WireGuard и свой конфиг на устройство.

## Конфигурация

Сетевые параметры находятся в приватной конфигурации. Ниже примеры; подставь значения своей сети:

```json
{ "wireguard": { "enabled": false, "interface": "wg0", "listenPort": 51820,
  "serverAddress": "10.77.0.1/24", "subnet": "10.77.0.0/24",
  "lanSubnet": "10.0.0.0/24", "dns": "10.0.0.1", "wanInterface": "eth0" } }
```

`stateDir` выбирает хранилище ключей/клиентов, иначе оно рядом с состоянием бота. `serverAddress`/`subnet` задают сеть туннеля, `lanSubnet` — маршрут клиента, `dns` — его DNS, `wanInterface` — LAN/NAT-интерфейс хоста. `listenPort` должен совпасть с UDP-пробросом. `enabled` информационный: явный запуск помощника устанавливает/включает/перезапускает интерфейс независимо от него.

## Сервер и устройства

```bash
npm run wireguard -- init
npm run wireguard -- peer alice-phone --endpoint home.example.com
```

`init` создаёт/переиспользует ключ сервера, записывает конфиг, устанавливает его в `/etc/wireguard` и перезапускает `wg-quick@<interface>`. `peer` сначала сохраняет клиентский конфиг, затем регистрирует устройство и устанавливает серверный. При неудаче установки ключ клиента сохранён, а `init` повторит установку. На неё приходится один рестарт.

`WG_ENDPOINT` может задать публичный адрес вместо `--endpoint`. Каждому устройству нужен свой peer. Файлы находятся в `<stateDir>/peers/<name>.conf` и необязательном `.png`; приватные ключи не печатаются. Передавай конфиги/QR приватно, исключай их из Git и диагностических архивов.

Импортируй файл устройства или отсканируй QR, включи туннель и открой приватный OpenCodez URL. Интерфейс и выбор серверов остаются прежними. Включение/выключение туннеля не требует рестарта бота.

## Проверка и ремонт

```bash
sudo systemctl status wg-quick@wg0 --no-pager
sudo wg show
```

Нет handshake — проверь endpoint, UDP-проброс и firewall. Есть handshake, но нет LAN — маршруты, `wanInterface`, forwarding и сам веб-сервис. Если LAN IP работает, а имя нет, отдельно проверь DNS.

Команды revoke у помощника нет. Для отзыва удали запись устройства из приватного `<stateDir>/peers.json`, выполни `npm run wireguard -- init`, затем убери старые конфиг/QR. Это явное изменение доступа; при простом отключении туннеля сохраняй материалы восстановления. Ремонт VPN не требует перезапуска Telegram-бота.
