# Первый запуск и обновление

[English](../en/first-run.md) · [Русский](first-run.md)

Нужны работающий сервер OpenCodez, Node 22+, токен от BotFather и твой числовой Telegram user ID. Запусти `npm run setup` в репозитории. Установщик спросит адрес сервера, необязательный пароль, домашнюю папку и адрес файлового gateway. Он запишет приватную конфигурацию, создаст artifact token и подготовит локальные папки и Compose mounts. Существующие файлы и серверы сохраняются. Адрес gateway должен быть доступен с хоста OpenCodez; это не обязательно адрес контейнера бота.

Запуск: `npm run deploy:bot` для Docker либо `npm ci`, затем `npm start` для Node. Развёртывание требует чистого Git checkout. Для путей Windows используй нативный Node либо SSH из Linux-контейнера: путь с буквой диска сам по себе не становится доступной папкой контейнера. Подробности — в [Docker](docker.md).

Добавь бота в группу с темами и выполни `/setup`. Бот проверит статус администратора, управление темами, закрепление и удаление сообщений. FILES и AUDIO создаются только при отсутствии их привязок; существующие служебные темы сохраняются. Бот закрепит инструкции, откроет General и отправит первую страницу гайда. Повторный setup продолжает ту же настройку.

Закрепи General, FILES и AUDIO в списке тем вручную: Bot API не умеет закреплять сами темы. Один раз открой личку с ботом и нажми Start, чтобы разрешить уведомления. После этого уведомления о завершении включаются автоматически. Явное отключение сохраняется в личных настройках. Если отдельный список получателей не задан, используются разрешённые user IDs.

## AUDIO

Выбери Подключить / изменить Groq. Зарегистрируйся на https://console.groq.com/home и создай ключ в API Keys. Отправь его в той же теме, где бот попросил ключ. Ввод привязан к разрешённому оператору и теме на 15 минут. Бот проверит ключ через endpoint моделей Groq и выберет `whisper-large-v3-turbo`. У бесплатного тарифа есть лимиты.

Ключ удаляется из входящего обновления до записи Telegram receipt journal. Сообщение с ним удаляется по возможности. Принятый ключ хранится в `provider-secrets.json` рядом с состоянием, с правами только для владельца. Он не попадает в preferences, логи, диагностику и обычный inbox. Исходное сообщение проходит через облачный транспорт Telegram; удаление не отменяет его доставку участнику группы, который уже успел его прочитать.

Существующие OpenRouter/direct-Groq настройки продолжают работать. Ключ, добавленный из Telegram, сохраняется как отдельное переопределение без редактирования read-only конфигурации контейнера. Расшифровки AUDIO остаются копируемым текстом и никогда не запускают агента автоматически.

## FILES

Setup отдельно показывает готовность gateway, подтверждённую доставку от агента и настройку сохранения входящих файлов. Включить файловый gateway создаёт приватный токен при необходимости и запускает listener. Compose уже публикует настроенный порт; при самостоятельном запуске нужно обеспечить доступ из доверенной сети.

Инструкция для плагина содержит универсальный промпт для агента и настроенный адрес gateway. Отдельный artifact token приходит в личный чат с ботом; сначала открой этот чат и нажми Start. Установи плагин и полный skill `telegram-artifact-send`. Заверши настройку отправкой небольшого файла в FILES. Успешная доставка сохраняет ограниченные метаданные хоста для отображения подтверждённого подключения. Проверка существующего транспорта не требует heartbeat или перезапуска OpenCodez. Сохранение входящих файлов нуждается в отдельном writable mount либо SSH transfer; доставка через плагин этого не подтверждает.

## Существующие установки

Перед обновлением останови бота и сохрани приватную копию config, state, provider secrets, Telegram inbox и mirror-marker journals. Сохрани том локального Bot API. Не запускай второй poller с production token.

Первый запуск новой версии импортирует прежние эффективные профили в preferences внутри `state.json`. Привязки, ожидающие темы, уведомления и маркеры доставки остаются у прежних владельцев. После импорта коллекция профилей и выбор по умолчанию управляются из Telegram. Профили в config — начальные данные установки, а не второй редактируемый каталог. Старые быстрые команды используют ту же логику. Удалённые профили не возвращаются, а сохранённые настройки тем позволяют reset и повторную попытку.

Для отката восстанови копию остановленного бота вместе с предыдущим образом. Один откат кода не отменяет миграцию preferences, смену адреса меню и новые входящие события. Перед возвратом к старому формату журналов прочитай [правила совместимости состояния](config-runtime.md#paths-and-state).
