# Озвучка финального ответа

[Русский](final-voice.md) · [English](../en/final-voice.md) · [Указатель](README.md)

Final Voice после **уже доставленного** текстового финала делает короткое резюме через API чата, озвучивает его через совместимый с OpenAI API `/v1/audio/speech` и отправляет голосовое сообщение ответом на тот самый финал Telegram. Опция выключена в публичном примере. Суммаризация и TTS выполняются отдельными провайдерами: в образе бота нет Python, FFmpeg, GPU или локальной модели.

## Конфигурация

В приватном `config.local.json` задайте `finalVoice.enabled: true`, параметры `summary` (`baseURL`, `model`, `apiKeyEnv`, при необходимости `requestBody`) и как минимум один профиль в `tts.profiles` с `baseURL`, `model`, `voices` и `defaultVoice`. `tts.defaultProfile` выбирает первоначальный профиль. Секреты задаются **только** переменными в `token.env`; имя переменной с ключом задаётся в конфиге. Пример для собственного совместимого сервиса:

```json
{
  "finalVoice": {
    "enabled": true,
    "summary": { "baseURL": "https://api.example.com", "model": "summary-model", "apiKeyEnv": "SUMMARY_API_KEY" },
    "tts": {
      "defaultProfile": "voice",
      "profiles": {
        "voice": {
          "baseURL": "http://tts-host:8000/v1",
          "apiKeyEnv": "TTS_API_KEY",
          "model": "speech-model",
          "voices": ["speaker"],
          "defaultVoice": "speaker",
          "responseFormat": "opus"
        }
      }
    }
  }
}
```

`summary.requestBody` передаёт провайдерские дополнительные настройки; бот сам выставляет модель, сообщения и `stream`. `finalVoice.queue.concurrency` и `maxPending` ограничивают параллелизм и память. `defaults.enabled`, `minFinalChars`, `introTemplate` задают исходные общие параметры; оператор потом меняет их через Telegram. Отключённая функция не делает запросов к провайдерам и не требует ключей при старте.

Встроенный промпт резюме и вступление рассчитаны на русскую речь. Для другого языка задайте `summary.defaultPrompt` и `defaults.introTemplate` в приватном конфиге и выберите подходящий TTS-профиль. `/lang` меняет интерфейс Telegram, а не язык озвучки.

## Команды

`/tts` и `/tts status` показывают готовность и общие параметры; `/tts on|off` управляет автоматической озвучкой. `/tts prompt [текст|reset]` меняет промпт суммаризации; `/tts voice [имя]` выбирает голос, `/tts engine [профиль]` — настроенный TTS, `/tts minlength N` — минимальную длину финала, `/tts intro [текст|off|reset]` — вступление. `/tts help` показывает подсказку. Эти же настройки доступны в панели General. `/speak` отвечает голосом на конкретное текстовое сообщение, Rich Message или цитату по запросу человека и не включает автоматический режим.

## Доставка и проверка

Автоматическая работа попадает в ограниченную фоновую очередь после отправки финального текста и никогда его не задерживает. Резюме и аудио не пишутся в логи, доступы к сервисам не передаются TTS помимо текста на озвучку. Проверьте сначала готовность через `/tts`, затем безопасный `/speak` и один новый финал. Если TTS или суммаризация недоступны, текст уже остаётся в топике; исправьте провайдера или ключ и повторите голос по запросу. Для остановки автоматических заданий выполните `/tts off`, затем при необходимости выключите `finalVoice.enabled` в приватном файле.
