# Озвучка финалов

[English](../en/final-voice.md) · [Русский](final-voice.md) · [Все языки](../README.md)

Final Voice добавляет короткую голосовую сводку после доставленного текстового ответа. Текст не ждёт озвучку. Бот владеет очередью и ответом Telegram; внешние OpenAI-совместимые сервисы создают сводку и звук.

```text
доставленный финал → очередь памяти → chat/completions → audio/speech → sendVoice
```

## Конфигурация

В публичном примере функция выключена. Задай `finalVoice.enabled`, провайдера сводки и хотя бы один профиль TTS в приватной конфигурации. Адреса, модели и ключи не подставляются автоматически.

```json
{ "finalVoice": {
  "enabled": true,
  "summary": { "baseURL": "https://api.example.com", "model": "summary-model", "apiKeyEnv": "SUMMARY_API_KEY" },
  "tts": { "defaultProfile": "voice", "profiles": { "voice": {
    "baseURL": "http://tts-host:8000/v1", "apiKeyEnv": "TTS_API_KEY", "model": "speech-model",
    "voices": ["speaker"], "defaultVoice": "speaker", "responseFormat": "opus"
  } } }
} }
```

`SUMMARY_API_KEY` и необязательный `TTS_API_KEY` хранятся в приватном окружении. Сводке нужна авторизация; TTS без заданного ключа не получает Authorization header. `summary.requestBody` допускает параметры провайдера, но `model`, `messages`, `stream` задаёт бот. Пределы, таймауты и список голосов контролирует оператор.

Исходные summary prompt/intro написаны для русского. Для другого языка задай `summary.defaultPrompt`, `defaults.introTemplate` и подходящий TTS-профиль. `/lang` меняет только интерфейс. В образе бота нет Python, PyTorch, FFmpeg и моделей; нужный TTS-инференс развёртывается отдельно.

## Команды и настройки

Используй **General → Настройки → Озвучка ответов** либо команды:

```text
/tts                         готовность и общие настройки
/tts on|off                  автоозвучка финалов
/tts status                  статус без запросов к провайдерам
/tts prompt [text|reset]     посмотреть/изменить промпт сводки
/tts voice [name]            список/выбор разрешённого голоса
/tts engine [profile]        список/выбор TTS-профиля
/tts minlength [number]      порог длины автоматического ответа
/tts intro [text|off|reset]  вступление
/tts help                    полная справка
/speak                       ответить на текст для одной озвучки
```

Настройки общие и сохраняются в `state.json`. Сброс темы не сбрасывает голосовые предпочтения. `/tts` без аргументов только показывает статус; кнопки устанавливают явные значения. Конфигурация ограничивает доступ к провайдерам, Telegram управляет автозапуском, промптом, профилем/голосом, порогом и вступлением.

## Доставка

Автоматической задаче нужны доставленный финал с точным Telegram ID, включённая автоозвучка, готовый провайдер и достаточная длина текста. Ожидающие/отправленные ID проверяются на повтор. Ограниченная очередь пропускает лишнюю автоматическую работу; ручной запрос получает сообщение о переполнении.

`/speak` принимает обычный/Rich-текст reply, подпись или цитату. Он не зависит от автоматического on/off и порога, но требует включённого доступа установки и провайдеров. Если на исходник нельзя ответить в этом чате, голос отвечает команде.

`{topicname}` и `{server}` во вступлении заполняются после сводки и не отправляются её провайдеру. Берётся актуальное имя активной темы; суффикс сервера убирается перед отдельным произнесением. Латинские обозначения вступления получают устойчивое русское произношение; пользовательский/агентский текст не меняется. Вступление отделено пустой строкой.

Рестарт сбрасывает незавершённую озвучку. Успешная доставка сохраняет ограниченные ID; авария между отправкой и отметкой может оставить неоднозначный результат. Ошибка провайдера не меняет текст, ручной статус становится просьбой повторить. Журналы содержат только рабочие метаданные, без промптов, сводок, тел ответов и аудиобайтов.

## Формат аудио

В `/audio/speech` идут штатные `model`, `input`, `voice`, `response_format`, `speed`. Предпочтителен OGG/Opus с сигнатурами `OggS` и `OpusHead`. MP3/M4A требуют совпадения запрошенного формата, Content-Type и сигнатуры. Ответ читается в ограниченный буфер; превышение прерывает его. WAV/PCM бот не перекодирует.

## Эксплуатация

Сначала разверни/проверь TTS, затем добавь конфигурацию/ключи и включи автоозвучку. Отключи прежнего отправителя тех же финалов до `/tts on`, иначе отправят оба. Проверь финал и ручной `/speak`, затем финалы двух тем с общими настройками. `/tts status` показывает готовность/очередь без запросов провайдерам. `/tts off` отключает автозапуск; `finalVoice.enabled=false` с рестартом отключает весь голосовой доступ.
