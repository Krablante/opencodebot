# Документация OpenCodeBot

🇷🇺 [Русский](README.md) · 🇬🇧 [English](../en/README.md) · [О проекте](../../README.ru.md)

Если бот ещё не установлен, начните с [README проекта](../../README.ru.md). Здесь пользовательские сценарии отделены от настройки и эксплуатации сервиса.

## Использование

- [Сценарии Telegram](telegram-workflow.md): топики, запросы, `/q`, `/reset`, откат, `/context`, вопросы и уведомления.
- [Панель General](control-menu.md): закреплённое меню и область действия команд.
- [Язык интерфейса](interface-language.md): переключение `/lang` и работа с каталогами переводов.

## Настройка и расширения

- [Конфигурация и состояние](config-runtime.md): приватные файлы, серверы, профили, хранение, речь и режим зеркала.
- [Шлюз артефактов](artifact-gateway.md): доставка файлов и текста, приём файлов от пользователя, HTTP API и плагин OpenCodez.
- [Озвучка ответа](final-voice.md): провайдеры суммаризации и TTS, команды и очередь.
- [WireGuard](wireguard.md): необязательный приватный доступ к браузеру через Linux-хост.

## Эксплуатация и разработка

- [Docker](docker.md): монтирования Compose, пути разных платформ, локальный Bot API и развёртывание.
- [Самообновление](self-update.md): проверки GitHub, Linux runner, ручное обновление и границы отката.
- [Разработка](development.md): зоны ответственности исходников, проверки и состояние работающего сервиса.

Те же имена файлов и категории есть в `docs/en/`. При изменении поведения или команды обновляйте обе версии вместе. Для нового языка создайте `docs/<код-языка>/` с теми же темами и добавьте ссылки в указатели: список языков не зашит в структуру документации.
